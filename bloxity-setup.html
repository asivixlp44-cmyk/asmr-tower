Description
ASMR Tower is a relaxing tower obby filled with satisfying slime, squishy and keyboard click sounds. Climb up the inside of a giant tower: wobbly jelly stairs, clicky keyboard bridges, squishy jelly domes, trusses and lime slime pools, waxed salted-butter blocks, pop-it paths, slime trampolines, sliding bubble wrap, typing keys, melting jelly, spinning mochi and the Rainbow Summit. Every surface has its own satisfying sound. Reach checkpoints for Coins, hatch cute squishy pets that multiply your Coins, collect trails, spin the lucky wheel and race your friends to the top. Grab gear like the Magic Carpet, Jetpack, Grappling Hook, coils and the Slap Tool!

Hosting steps

  1. hosting.bloxity.io: create the app asmr-tower and copy its deploy token.
  2. GitHub: an empty public repo asivixlp44-cmyk/asmr-tower with the secret LEGION_DEPLOY_TOKEN, then push main (the workflow builds and deploys).
  3. Check https://asmr-tower.host.bloxity.io/health and play at https://asmr-tower.play.bloxity.io.
  4. Create the game in Manage Games with the values above (slug exactly asmr-tower) and add the IAPs.
  5. Set LEGION_WEBHOOK_SECRET on the server so purchases cost real Bux.
